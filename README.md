# AI CRO Agent
AI-powered Landing Page CRO Audit Agent.
## About
This project analyzes a website or Shopify product page and provides a CRO audit based on the information available on the page.
The user enters a website URL and the system analyzes the page content and generates:
- CRO score out of 100
- Hero section analysis
- CTA quality
- Trust signals
- Product page issues
- Mobile UX observations
- Copy and message clarity
- Friction points
- Recommended improvements
